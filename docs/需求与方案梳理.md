# 雅思在线课程网站 —— 需求与技术方案梳理

> 版本：v0.1（草案）  日期：2026-06-20
> 本文档用于产品/技术对齐，覆盖功能需求、非功能需求、视频安全方案与技术选型。带 **【待确认】** 标记的为需要业务侧拍板的决策点。

---

## 0. 项目概述

一个面向 C 端学员的雅思在线课程平台，核心链路为：
**微信登录 → 浏览课程 → 微信支付下单 → 观看视频/下载课件 → 记录学习进度**。
重点诉求是**内容安全**：视频防下载、防转发、动态水印、防录屏溯源。

### 形态选择 【待确认】
| 形态 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| 微信公众号 H5（推荐起步） | 微信登录/支付最顺、开发快、传播方便 | 受微信浏览器限制、防录屏弱 | 快速上线 |
| 微信小程序 | 体验好、支付原生、有一定防护 | 视频组件受限、审核严（教育类目资质） | 中长期 |
| 独立 App（iOS/Android） | 防录屏/防下载能力最强（可调用系统级 API） | 成本高、上架周期长 | 强安全诉求 |
| PC Web | 大屏学习体验好 | 防下载最弱、微信登录需扫码 | 辅助端 |

> 建议：**一期做微信生态 H5 + PC Web**，二期视盈利情况补小程序/App。安全等级要求极高时优先 App。

## 2. 功能需求

### 2.1 账号与登录
- **微信登录**
  - H5：微信公众号网页授权（OAuth2，`snsapi_userinfo` 获取昵称头像）。
  - PC：微信开放平台扫码登录（`UnionID` 打通多端身份）。
  - 小程序（若做）：`wx.login` + `code2session`。
  - **统一以 UnionID 作为用户主键**，保证 H5/PC/小程序为同一账号。
- 首次登录自动注册，记录昵称、头像、openid、unionid、注册时间、来源渠道。
- **手机号绑定** 【待确认】：是否强制绑定手机号（用于找回、风控、客服）。建议购买前绑定。
- 登录态：服务端 Session/JWT，Token 有效期 + 刷新机制。
- 退出登录、账号注销（合规要求，需提供）。

### 2.2 课程信息与价格展示
- **课程结构**：课程（Course）→ 章节（Chapter）→ 课时（Lesson/Video）。
- 课程详情字段：标题、封面、简介、适合人群、目标分数、讲师介绍、大纲目录、总课时数、总时长、有效期、原价/现价、销量/评价（可选）。
- **试看**：每课程可配置若干免费试看课时或片段（前 N 分钟）。
- **价格策略** 【待确认】：
  - 单课程购买 / 课程包（套餐）/ 会员订阅（包月包年）/ 限时折扣 / 优惠券 / 拼团？
  - 建议一期：单课程 + 课程包 + 优惠券，订阅二期。
- **有效期模型** 【待确认】：永久 / 购买后 N 天 / 固定到期日。影响访问鉴权逻辑。
- 课程上下架、排序、分类（如听说读写、冲分班、基础班）、标签、搜索。

### 2.3 下单与支付（微信支付）
- 下单流程：选课 → 创建订单（待支付）→ 调起微信支付 → 支付回调 → 订单完成 → 发放课程权限。
- **微信支付方式**：
  - H5（公众号内）→ JSAPI 支付。
  - H5（非微信浏览器）→ H5 支付。
  - PC → Native 支付（扫码）。
  - 小程序 → 小程序支付。
- **关键可靠性设计**：
  - 订单幂等（防重复下单、防重复回调）。
  - 以**异步回调**为准发放权限，前端跳转结果仅作展示。
  - 主动查单兜底（回调丢失时定时轮询微信查单接口）。
  - 超时未支付自动关单。
  - 金额校验（防篡改：服务端重新计算金额，不信任前端传值）。
- **退款**：支持后台发起退款，退款后回收课程权限。退款规则【待确认】（如已观看比例限制）。
- 对账：每日与微信账单对账，记录交易流水。
- 发票 【待确认】：是否开电子发票。

### 2.4 视频观看
- 播放器：支持清晰度切换、倍速、进度记忆、断点续播、字幕（雅思场景常需中英字幕）。
- **加密播放**（详见第 4 节安全方案）。
- 续播：记录上次观看位置，下次自动跳转。
- 防盗链、按需鉴权获取播放地址（一次一签、短时效）。
- 多端同时观看限制 【待确认】（如同账号仅允许 1 端在线，防共享账号）。
- 移动网络播放提醒、预加载策略。

### 2.5 课件下载
- 课件类型：PDF、音频（雅思听力）、Word、图片等。
- **权限控制**：仅已购且在有效期内可下载。
- **下载安全**：
  - PDF 动态水印（用户手机号/ID）。
  - 下载链接短时效签名（防止链接被转发长期有效）。
  - 是否允许下载 vs 仅在线预览 【待确认】（音频建议仅在线播放，PDF 可水印下载）。
- 下载次数/频率限制，记录下载日志。

### 2.6 学习记录
- 记录维度：每课时观看时长、进度百分比、最后观看位置、是否看完、首次/最近观看时间。
- 课程级聚合：整体完成度、累计学习时长、连续学习天数（打卡）。
- 客户端定时上报进度（如每 15s/30s 心跳上报），服务端去重合并。
- 我的课程页：在学/已完成、继续学习入口。
- 学习数据看板（后台）：课程完播率、用户活跃、转化漏斗。

### 2.7 后台管理系统
- 课程管理（CRUD、上下架、章节课时编排、视频/课件上传转码）。
- 价格/优惠券/活动配置。
- 订单与退款管理、对账。
- 用户管理（查询、封禁、权限调整）。
- 水印与防护策略配置。
- 数据统计看板。
- 操作审计日志。

### 2.8 其他（建议纳入）
- 消息通知：购买成功、课程更新、有效期到期提醒（公众号模板消息/订阅消息）。
- 客服入口、常见问题 FAQ。
- 评价/评论（可选）。
- 分享裂变：分销/邀请返现 【待确认】（涉及微信合规，慎重）。

## 4. 视频与内容安全方案（核心）

> 必须明确认知：**Web/H5 端无法 100% 防下载/防录屏**，目标是「显著提高盗录成本 + 泄露可溯源追责」。强防护需走 App 或专业版权云（如阿里云视频点播 VOD / 腾讯云点播 + 私有加密）。

### 4.1 防下载 / 防盗链
- **不直接暴露视频真实地址**，播放时按需请求带签名的临时地址（URL 鉴权，几分钟有效）。
- **HLS 切片 + AES-128 加密**：视频转码为 m3u8 切片，密钥通过鉴权接口动态下发，密钥地址需登录态校验。
- **私有加密（推荐）**：使用云厂商私有加密方案（阿里云 VOD「私有加密」/ 腾讯云点播加密），密钥与播放器绑定，普通下载工具无法解密拼接。
- Referer/IP/UA 校验、防盗链 Token。
- 关闭右键、禁用浏览器原生 download 属性（仅基础防护，象征意义）。

### 4.2 DRM（最强防护，按需）【待确认】
- Widevine（Android/Chrome）/ FairPlay（iOS/Safari）/ PlayReady。
- 成本与集成复杂度高，适合高客单价/强版权诉求。一期可先用 HLS 私有加密，二期评估 DRM。

### 4.3 动态水印（防转发/防录屏溯源）
- **跑马灯水印**：播放器上叠加半透明、缓慢移动的用户标识（手机号后四位 + 用户ID + 时间戳），位置随机移动，难以裁剪去除。
- 前端 DOM 水印 + 防篡改（MutationObserver 监听水印被删则停播）。
- **服务端烧录水印（更强）**：对关键课程在转码时将用户信息烧进画面（需按用户切片，成本高，适合点对点）。
- PDF 课件水印：下载时实时生成带用户信息的水印 PDF。
- 目的：一旦视频外流，可通过水印定位泄露源头并追责。

### 4.4 防录屏
- App 端：iOS `isCaptured`/`UIScreen.capturedDidChangeNotification`、Android `FLAG_SECURE` 禁止截屏录屏。
- Web/H5：无法真正禁止，依赖水印溯源 + 协议约束。
- 检测到投屏/录屏时降级（暂停、打码、加重水印）。

### 4.5 账号与播放风控
- 同账号多端并发播放限制（踢下线）。
- 异常行为检测：短时间大量拉取切片、异常 IP/设备、自动化请求 → 限流/封禁。
- 单设备/设备指纹绑定 【待确认】（防一号多人共享）。
- 播放鉴权：每次获取播放凭证校验「登录态 + 已购 + 有效期 + 并发数」。

### 4.6 传输与存储安全
- 全站 HTTPS；视频/课件存私有 Bucket，禁止公开读。
- 上传/转码在内网完成，源文件不对外。
- 密钥管理用 KMS，不硬编码。

## 5. 技术架构（建议）

### 5.1 推荐选型
- **前端**：H5/PC 用 Vue3 或 React + TS；小程序用原生或 Taro/uni-app（可一套多端）。
- **播放器**：阿里云 prism player / 腾讯云 TCPlayer（自带加密、水印、防盗链）或 video.js + hls.js 自研。
- **后端**：Java(Spring Boot) 或 Node(NestJS) 或 Go；微服务可选，初期单体+模块化即可。
- **存储**：MySQL（业务）、Redis（缓存/登录态/限流）、对象存储（OSS/COS）。
- **视频点播**：**强烈建议用云厂商 VOD**（阿里云 VOD / 腾讯云点播），自带转码、加密、CDN、防盗链、播放统计，省去自建转码与安全成本。
- **CDN**：视频与课件走 CDN + URL 鉴权。
- **消息队列**：支付回调、转码通知、进度上报削峰（Kafka/RabbitMQ/RocketMQ）。

### 5.2 关键外部依赖与资质 【需提前准备】
- 微信公众号（已认证服务号，含网页授权、JSAPI 支付、模板消息）。
- 微信开放平台（PC 扫码登录、UnionID 打通）。
- 微信商户号（微信支付，需营业执照、结算账户、教育类目资质）。
- 小程序（若做，教育类目可能需 ICP/办学相关资质）。
- 域名 + ICP 备案 + HTTPS 证书。
- 云厂商 VOD/CDN/OSS 账号。

### 5.3 核心数据模型（草案）
```
User(id, unionid, openid_h5, openid_mini, nickname, avatar, phone, status, created_at)
Course(id, title, cover, intro, category, price, original_price, validity_type, validity_days, status, sort)

```

## 6. 关键业务流程

### 6.1 支付链路（以异步回调为权威）
```
用户下单 → 创建订单(待支付) → 调起微信支付
   ↓                                  ↓ 用户付款
前端跳转结果页(仅展示) ← ── ── ── 微信异步回调 → 验签 → 幂等校验 → 标记已支付 → 发放 Entitlement → 通知用户
                                          ↑
                              定时主动查单兜底(防回调丢失)
```

### 6.2 视频播放鉴权
```
点击播放 → 请求播放凭证接口
   → 校验[登录态 + 已购该课 + 在有效期 + 并发未超限 + 风控通过]
   → 通过则下发[短时效播放地址 + 解密密钥凭证 + 水印参数(用户ID/手机尾号/时间)]
   → 播放器加载加密HLS，叠加跑马灯水印
   → 心跳上报进度 & 在线状态
```

# 详细设计（基于已拍板决策）

## 9. 基于决策的细化说明

### 9.1 终端：PC Web 为主
- **PC Web**：主战场。微信登录走**微信开放平台扫码登录**（需开放平台账号 + 网站应用），拿 `UnionID`。微信支付走 **Native 扫码支付**。
- **微信 H5（公众号内）**：辅助端。网页授权登录（`snsapi_userinfo`），支付走 **JSAPI**。
- 两端通过 **UnionID 统一账号**。需同时申请：微信开放平台（网站应用，PC 用）+ 微信公众号服务号（H5 用），二者绑定到同一开放平台主体以打通 UnionID。
- 响应式：PC 优先布局，H5 适配移动端。

### 9.2 安全：不做 DRM/防录屏（详见第 4 节）
- 采用：腾讯云点播**私有加密** + **HLS 防盗链 Key（KEY 防盗链）** + **前端动态跑马灯水印** + **播放凭证短时效** + **单端在线** + **风控限流**。
- 不投入 DRM（Widevine/FairPlay）与 App 级 `FLAG_SECURE`。承认 Web 端无法绝对防录屏，靠**水印溯源追责**兜底。

### 9.3 价格模型（单课 + 套餐 + 订阅 + 优惠券）
- **单课（Course）**：购买单门课程，按该课程有效期规则授权。
- **套餐/课程包（Bundle）**：一次购买多门课程，价格优于单买；授权 = 展开为各课程的 Entitlement。
- **订阅（Subscription）**：包月/包季/包年，订阅期内可观看**订阅范围内**所有课程。
  - 订阅范围 【待确认细节】：全站可看 vs 指定订阅专区。建议「订阅专区」，新/高价课程可排除。
  - 续费：一期可做**手动续费**（到期前提醒），自动扣费（微信委托代扣）二期再上。
  - 订阅期内权限是「动态判定」：播放鉴权时校验「订阅有效 且 课程在订阅范围」，不预生成 Entitlement。
- **优惠券（Coupon）**：满减/折扣/指定课程券；下单时校验适用范围、有效期、是否已用。金额计算**全部在服务端**完成。
- 价格优先级与叠加规则 【待确认】：优惠券能否与套餐叠加？建议一期「不可叠加，取最优」。

### 9.4 有效期：按课程粒度
- `Course.validity_type`：`PERMANENT`（永久）/ `DAYS`（购买后 N 天）/ `FIXED_DATE`（固定到期日）。
- 购买时按课程规则计算 `Entitlement.expire_at`（永久则为 NULL）。
- 订阅来源的访问不写死到期，按订阅状态实时判定。
- 到期前 N 天发提醒，到期后课程进入「已过期」，可引导续费/复购。

### 9.5 全面禁下载
- 视频：仅加密 HLS 在线播放，不提供任何下载入口；播放地址短时效。
- 课件：**仅在线预览**（PDF 用前端渲染如 PDF.js，禁用下载/打印按钮；图片/音频在线展示）。
- 课件预览同样叠加用户水印；预览地址短时效签名。
- 明确：禁下载是「无下载入口 + 短时效地址 + 水印」，技术上仍无法绝对阻止抓包，靠水印溯源。

### 9.6 账号：强绑手机号 + 单端在线
- **强绑手机号**：微信登录后，若未绑手机号则强制进入绑定页（短信验证码），未绑定不可购买/观看。
- **单端在线**：
  - 每次登录生成 `session_id` 写入 Redis（key = userId，记录当前活跃 session/设备）。
  - 新登录覆盖旧 session；旧端下次请求/播放心跳校验失败 → 被踢下线提示「账号在别处登录」。
  - 播放凭证发放也校验当前 session 是否为活跃端，杜绝多端并发播放。

### 9.7 讲师角色与后台
- **讲师权限**：管理「自己名下」课程的章节/课时/课件，上传视频（提交到 VOD 转码），编辑课程介绍、大纲；查看自己课程的学习数据（完播率、学员进度）。
- **不可**：定价审核、上下架终审、看全站订单、提现结算由管理员控制。
- **结算** 【待确认】：是否需要讲师分成/提现报表？若需要则加结算模块。
- 工作流 【待确认】：讲师编辑后是否需管理员审核才上架？建议「讲师提交 → 管理员审核上架」。

### 9.8 腾讯云 VOD 落地
- 上传：后台/讲师上传 → 调用 VOD 服务端上传或客户端签名直传 → 触发**任务流**（转码为多码率 HLS + **私有加密** + 截图）。
- 播放：服务端用 VOD **播放器签名（PlayerSign）下发**，集成 **TCPlayer**（Web 播放器），开启：
  - **Referer/Key 防盗链**、**私有加密播放**、**播放器动态水印（跑马灯）**。
  - `fileId` + 短时效 `psign`，psign 内绑定 userId/水印参数。
- 统计：使用 VOD 播放统计 + 自建心跳上报双轨，学习记录以自建为准。
- 课件：存腾讯云 **COS**（私有读）+ **CDN 签名 URL（短时效）** 预览。

## 10. 核心数据模型 DDL（草案，MySQL）

> 仅核心表，省略索引/分库；金额单位「分」，时间统一 UTC。

```sql
-- 用户
CREATE TABLE `user` (
  id            BIGINT PRIMARY KEY AUTO_INCREMENT,
  unionid       VARCHAR(64) UNIQUE,             -- 跨端统一身份
  openid_h5     VARCHAR(64),                    -- 公众号 openid
  openid_web    VARCHAR(64),                    -- 开放平台 openid
  nickname      VARCHAR(64),
  avatar        VARCHAR(255),
  phone         VARCHAR(20) UNIQUE,             -- 强制绑定
  status        TINYINT DEFAULT 1,             -- 1正常 0封禁
  created_at    DATETIME, updated_at DATETIME
);

-- 角色（管理员/讲师），学员默认无需该表
CREATE TABLE `staff` (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT, role VARCHAR(20),            -- ADMIN / TEACHER
  status TINYINT, created_at DATETIME
);

-- 课程
CREATE TABLE `course` (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  title VARCHAR(128), cover VARCHAR(255), intro TEXT,
  category_id BIGINT, teacher_id BIGINT,        -- 讲师
  price INT, original_price INT,                -- 分
  validity_type VARCHAR(16),                    -- PERMANENT/DAYS/FIXED_DATE
  validity_days INT, fixed_expire_at DATETIME,
  in_subscription TINYINT DEFAULT 0,            -- 是否纳入订阅范围
  status VARCHAR(16),                           -- DRAFT/REVIEWING/ONLINE/OFFLINE
  sort INT, created_at DATETIME, updated_at DATETIME
);

CREATE TABLE `chapter` (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  course_id BIGINT, title VARCHAR(128), sort INT
);

CREATE TABLE `lesson` (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  chapter_id BIGINT, course_id BIGINT,
  title VARCHAR(128), vod_file_id VARCHAR(64),  -- 腾讯云 VOD fileId
  duration INT, free_trial TINYINT DEFAULT 0,   -- 是否试看
  sort INT
);

-- 课件（仅在线预览，禁下载）
CREATE TABLE `material` (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  course_id BIGINT, lesson_id BIGINT,
  name VARCHAR(128), type VARCHAR(16),          -- PDF/IMAGE/AUDIO
  cos_key VARCHAR(255), preview_only TINYINT DEFAULT 1
);

-- 套餐
CREATE TABLE `bundle` (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  title VARCHAR(128), price INT, status VARCHAR(16)
);
CREATE TABLE `bundle_course` (bundle_id BIGINT, course_id BIGINT);

-- 订阅计划与用户订阅
CREATE TABLE `sub_plan` (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  title VARCHAR(64), period VARCHAR(16),        -- MONTH/QUARTER/YEAR
  price INT, status VARCHAR(16)
);
CREATE TABLE `user_subscription` (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT, plan_id BIGINT,
  start_at DATETIME, expire_at DATETIME,
  status VARCHAR(16)                            -- ACTIVE/EXPIRED/CANCELED
);

-- 优惠券
CREATE TABLE `coupon` (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(64), type VARCHAR(16),           -- FULL_CUT/DISCOUNT
  rule_json JSON,                               -- 满减阈值/折扣/适用范围
  start_at DATETIME, end_at DATETIME, status VARCHAR(16)
);
CREATE TABLE `user_coupon` (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT, coupon_id BIGINT,
  status VARCHAR(16), used_order_id BIGINT, received_at DATETIME
);

-- 订单（支持单课/套餐/订阅）
CREATE TABLE `order` (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  order_no VARCHAR(32) UNIQUE,
  user_id BIGINT,
  item_type VARCHAR(16),                        -- COURSE/BUNDLE/SUBSCRIPTION
  item_id BIGINT,
  origin_amount INT, discount_amount INT, pay_amount INT,
  coupon_id BIGINT,
  status VARCHAR(16),                           -- UNPAID/PAID/CLOSED/REFUNDED
  pay_channel VARCHAR(16),                      -- NATIVE/JSAPI/H5
  wx_transaction_id VARCHAR(64),
  paid_at DATETIME, created_at DATETIME, closed_at DATETIME
);

-- 课程权限（单课/套餐购买生成；订阅不在此表，实时判定）
CREATE TABLE `entitlement` (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT, course_id BIGINT,
  source VARCHAR(16),                           -- COURSE/BUNDLE
  source_order_id BIGINT,
  expire_at DATETIME,                           -- NULL=永久
  status VARCHAR(16),                           -- ACTIVE/EXPIRED/REVOKED
  UNIQUE KEY uk_user_course (user_id, course_id)
);

-- 学习记录
CREATE TABLE `watch_record` (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT, lesson_id BIGINT, course_id BIGINT,
  progress INT,                                 -- 百分比
  last_position INT,                            -- 秒
  duration_watched INT,                         -- 累计观看秒
  finished TINYINT, updated_at DATETIME,
  UNIQUE KEY uk_user_lesson (user_id, lesson_id)
);

-- 退款
CREATE TABLE `refund` (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  order_id BIGINT, amount INT, reason VARCHAR(255),
  status VARCHAR(16), wx_refund_id VARCHAR(64), created_at DATETIME
);
```

Redis 关键 key：
- `login:session:{userId}` → 当前活跃 sessionId/设备（单端在线）。
- `play:token:{token}` → 播放凭证（短时效）。
- 限流：`rl:play:{userId}`、`rl:material:{userId}`。

## 11. 接口清单（草案，REST）

### 认证
- `GET  /api/auth/wx/qrcode` PC 扫码登录二维码/ticket
- `GET  /api/auth/wx/callback` 微信授权回调换 token
- `POST /api/auth/phone/send-code` 发送短信验证码
- `POST /api/auth/phone/bind` 绑定手机号
- `POST /api/auth/logout`

### 课程
- `GET /api/courses` 列表（分类/搜索/分页）
- `GET /api/courses/{id}` 详情（含大纲、价格、试看标记）
- `GET /api/courses/{id}/materials` 课件列表（仅元信息）
- `GET /api/bundles` / `GET /api/sub-plans`

### 订单与支付
- `POST /api/orders` 创建订单（type+itemId+couponId，服务端算价）
- `POST /api/orders/{no}/pay` 调起微信支付（返回 Native/JSAPI 参数）
- `POST /api/pay/wx/notify` 微信支付异步回调（验签+幂等+发权限）
- `GET  /api/orders/{no}` 查单（前端轮询 + 兜底主动查单）
- `POST /api/orders/{no}/refund` 申请退款（后台/规则内）

### 播放与课件（鉴权核心）
- `POST /api/play/credential` 获取播放凭证：入参 lessonId；服务端校验[登录+已购/订阅+有效期+单端在线+风控]→ 返回 VOD fileId + psign + 水印参数
- `GET  /api/materials/{id}/preview-url` 获取课件短时效预览签名 URL
- `POST /api/play/heartbeat` 播放心跳（上报位置/时长 + 维持单端在线校验）

### 学习记录
- `GET  /api/me/courses` 我的课程（在学/已完成）
- `GET  /api/me/records?courseId=` 学习记录
- `POST /api/me/records` 进度上报（与心跳合并亦可）

### 讲师后台
- `POST /api/teacher/courses` / `PUT .../{id}` 课程编辑（提交审核）
- `POST /api/teacher/lessons` + VOD 上传签名 `GET /api/teacher/vod/upload-sign`
- `GET  /api/teacher/courses/{id}/stats` 学习数据

### 管理后台
- 课程/套餐/订阅/优惠券 CRUD、审核上下架
- 订单/退款/对账、用户管理、水印策略、数据看板、审计日志

| # | 决策项 | 结论 / 建议 |
