## 0. 全局约定

### 0.1 端与导航
- **PC Web（主）**：顶部全局导航 = Logo｜课程｜套餐｜订阅会员｜我的学习｜（右）搜索框｜登录/头像下拉。
- **H5（辅）**：底部 Tab = 首页｜课程｜我的学习｜我的。顶部为页面标题栏。
- 头像下拉（已登录）：我的学习、我的订单、账号设置、退出登录；讲师/管理员显示「进入后台」。

### 0.2 登录态与拦截
- 未登录可浏览：首页、课程列表、课程详情、套餐/订阅介绍、试看。
- 需登录拦截：购买、观看正课、课件预览、我的学习、订单、设置 → 触发登录弹窗/页。
- **未绑手机号拦截**：登录后任何「购买/观看」动作前，强制进入绑定手机号页。
- **单端在线提示**：当前端被踢时，全局弹层「你的账号已在其他设备登录，请重新登录」，停止播放。

### 0.3 通用组件
- 登录弹窗（扫码/公众号授权）、手机号绑定弹窗、支付弹窗、全局 Toast、空状态、加载骨架、分页/无限滚动、面包屑（PC）。

## 2. C 端页面详述

### C1 首页 `/`
- **用途**：品牌曝光 + 引导浏览/购买。
- **模块**：
  1. 顶部 Banner 轮播（活动/主推课程，可配置跳转）。
  2. 订阅会员入口卡片（突出权益与价格）。
  3. 精选课程模块（按分类 Tab：听/说/读/写/冲分/基础）。
  4. 热门套餐推荐。
  5. 讲师风采（可选）、学员评价/案例（可选）。
  6. 底部：关于我们、FAQ、客服、ICP 备案号、协议链接。
- **交互**：卡片点击进详情；分类 Tab 切换；CTA「立即订阅/查看课程」。
- **异常**：无网络/接口失败 → 骨架 + 重试。
- **权限**：游客可见。

### C2 课程列表 `/courses`
- **用途**：检索筛选课程。
- **模块**：
  - 筛选区：分类、目标分数（5.5/6/6.5/7+）、班型（基础/强化/冲分）、价格区间、是否含订阅。
  - 排序：综合 / 最新 / 销量 / 价格升降。
  - 列表卡片：封面、标题、讲师、目标分、课时数、价格（划线原价+现价）、「订阅可看」角标、销量。
  - 分页（PC）/ 上拉加载（H5）。
- **交互**：筛选即时刷新；卡片进详情。
- **状态**：空结果空状态；加载骨架。
- **权限**：游客可见。

### C3 课程详情 `/course/:id`（核心转化页）
- **用途**：展示课程价值 + 转化购买/观看。
- **模块**：
  1. 头图区：封面/试看预览、标题、讲师、目标分、有效期说明、销量、价格区。
  2. **CTA 区（按用户状态动态）**：
     - 未购未订阅 → 「立即购买 ¥xxx」+「订阅可看」标识（若在专区）。
     - 已购/订阅有效 → 「开始学习 / 继续学习」。
     - 已过期 → 「已过期，去续费/复购」。
  3. 课程大纲（章节 → 课时，标注时长、试看角标、锁/解锁状态）。
  4. 课件清单（仅展示名称/类型，标「在线预览」，无下载按钮）。
  5. 课程介绍（适合人群、学习目标、详情富文本）。
  6. 讲师介绍卡。
  7. 配套套餐/订阅交叉推荐。
  8. 评价区（可选，二期）。
- **交互**：
  - 点试看课时 → 直接进播放页（试看片段，VOD `Try` 时长）。
  - 点锁定课时 → 引导购买/订阅。
  - 点「购买」→ 收银台 C8（先校验登录 + 手机号）。
- **状态**：下架课程 404/提示；价格活动倒计时（若有）。
- **权限**：游客可见；购买/正课观看需登录+绑手机。

### C4 视频播放页 `/learn/:courseId/:lessonId`（核心体验页）
- **用途**：加密视频观看 + 学习。
- **布局（PC）**：左播放器 + 右侧课程目录（章节/课时切换，标记已学/进度）。下方：课件预览入口、课程信息、笔记（可选二期）。
- **播放器（TCPlayer）功能**：
  - 清晰度切换、倍速（0.5–2x）、音量、全屏、字幕开关（中/英）。
  - **断点续播**：进入自动跳到 `last_position`，提示「上次看到 xx:xx，继续/重新」。
  - **动态跑马灯水印**：半透明显示「手机尾号+用户ID+时间」，缓慢随机移动，不可关闭；水印 DOM 被篡改则暂停播放。
  - 倍速/清晰度记忆。
- **鉴权交互**：进入页 → 调 `POST /api/play/credential`；
  - 未购/订阅无效 → 拦截，弹「购买/订阅」引导，仅可看试看节。
  - 单端校验失败 → 踢下线提示。
- **学习上报**：每 15–30s 心跳上报（位置/累计时长）+ 暂停/切节/离开时补报；驱动进度与完播。
- **状态与异常**：
  - 凭证过期 → 自动续签重试。
  - 网络差 → 自动降码率 + 提示。
  - 非活跃端继续播放 → 暂停 + 踢出。
- **权限**：登录 + （已购/订阅有效 或 试看节）。

### C5 课件预览 `/material/:id`
- **用途**：在线预览课件，**禁止下载/打印**。
- **模块**：PDF.js 渲染（PDF）；图片查看器；音频在线播放器。叠加用户水印。
- **交互**：翻页/缩放（PDF）；预览地址短时效，过期重新获取。禁用右键/下载/打印按钮。
- **权限**：登录 + 拥有该课程权限。

### C6 套餐 `/bundles` `/bundle/:id`
- **列表**：套餐卡（标题、含课程数、原价合计、套餐价、节省金额）。
- **详情**：包含课程清单（可点进各课详情）、套餐价、购买 CTA、有效期说明（按各课程规则）。
- **交互**：购买 → 收银台（itemType=BUNDLE）。
- **权限**：游客可见，购买需登录。

### C7 订阅会员 `/subscribe`
- **用途**：售卖订阅，展示订阅专区权益。
- **模块**：
  1. 权益说明（订阅专区可看范围、可看课程数、更新承诺）。
  2. 套餐选择：月/季/年（价格、日均价、推荐角标）。
  3. 订阅专区课程预览（in_subscription=1 的课程列表）。
  4. 当前订阅状态（已订阅显示到期日 + 续费入口）。
  5. FAQ（订阅不含哪些课、到期后内容如何）。
- **交互**：选周期 → 收银台（itemType=SUBSCRIPTION）。
- **权限**：游客可见，购买需登录。

### C8 收银台 `/checkout`（核心支付页）
- **用途**：确认订单 + 选券 + 支付。
- **模块**：
  1. 商品信息（课程/套餐/订阅，含有效期说明）。
  2. 价格明细：原价、优惠券抵扣、应付（**金额由服务端返回，前端只展示**）。
  3. 优惠券选择（仅展示可用券，不可叠加、取最优；置灰不可用券+原因）。
  4. 支付方式：PC=微信扫码（Native）；H5=微信支付（JSAPI）。
  5. 协议勾选（用户协议/购买须知，禁退/退款规则提示）。
- **交互流程**：
  - 进入校验登录 + 手机号（缺则先绑定）。
  - 创建订单 `POST /api/orders` → 调起支付 `POST /api/orders/{no}/pay`。
  - PC：展示二维码 + 轮询 `GET /api/orders/{no}` 状态；扫码成功跳 C9。
  - H5：拉起微信收银台，返回后跳 C9。
- **状态与异常**：
  - 重复下单防护（同商品未支付订单复用/关闭旧单）。
  - 券失效/被抢用 → 重算价格提示。
  - 二维码过期 → 刷新。
  - 支付超时未付 → 关单提示。
- **权限**：登录 + 绑手机。

### C9 支付结果 `/pay/result`
- **用途**：展示支付结果（**以服务端订单状态为准，非微信前端跳转**）。
- **模块**：成功（去学习/查看订单）；处理中（轮询/稍后查看）；失败（重试/换方式）。
- **交互**：成功 → 「立即学习」直达课程；处理中 → 轮询订单状态。
- **权限**：登录。

### C10 我的学习 `/my/learning`
- **模块**：
  - Tab：在学 / 已完成 / 已过期。
  - 课程卡：封面、标题、整体进度条、上次学到、有效期/到期提醒、「继续学习」。
  - 订阅来源课程标识「订阅中」。
- **交互**：继续学习 → 跳到 last_position 的课时（C4）。
- **状态**：空状态「去逛逛课程」。
- **权限**：登录。

### C11 我的订单 `/my/orders`
- **模块**：订单列表（订单号、商品、金额、状态、时间）；筛选状态。
- **状态**：待支付（去支付/取消）、已支付、已关闭、已退款。
- **交互**：详情查看；待支付 → 继续支付；符合规则 → 申请退款。
- **权限**：登录（仅本人订单）。

### C12 我的优惠券 `/my/coupons`
- **模块**：可用 / 已用 / 已过期 Tab；券面（名称、面额、适用范围、有效期、去使用）。
- **权限**：登录。

### C13 我的订阅 `/my/subscription`
- **模块**：当前订阅状态、到期日、剩余天数、续费按钮、订阅历史。到期前 N 天提醒。
- **权限**：登录。

### C14 账号设置 `/my/settings`
- **模块**：头像/昵称（来自微信）、手机号（已绑，可换绑）、账号注销入口、协议查看。
- **交互**：换绑手机号（验证码）；注销（二次确认 + 合规说明）。
- **权限**：登录。

### C15 登录 / 绑定手机号
- **登录弹窗**：
  - PC：微信扫码（展示二维码，轮询 `GET /api/auth/wx/qrcode` 状态 → 成功换 token）。
  - H5：公众号内静默/手动授权。
- **绑定手机号弹窗**：手机号 + 短信验证码（60s 倒计时、防刷）；未绑不可购买/观看。
- **异常**：二维码过期刷新；验证码错误/超频限制。

### C16 搜索结果 `/search?q=`
- **模块**：关键词回显、结果列表（复用课程卡）、无结果空状态、热门搜索词。
- **权限**：游客可见。

## 3. 讲师后台页面

> 入口：头像下拉「进入后台」→ `/teacher`。权限：role=TEACHER，仅限本人名下课程。

| # | 页面 | 路由 | 说明 |
|---|---|---|---|
| T1 | 工作台 | `/teacher` | 我的课程数、待审核、学习数据概览 |
| T2 | 我的课程 | `/teacher/courses` | 列表（状态：草稿/审核中/已上线/已下线），新建/编辑 |
| T3 | 课程编辑 | `/teacher/course/:id` | 基本信息、大纲（章节/课时增删排序）、课件、提交审核 |

  - 编辑后「提交审核」→ 状态 REVIEWING，等管理员审核上架（按建议默认）。

- **限制**：无定价权、无上下架终审、无订单/财务数据。

## 5. 关键状态机（页面相关）

### 5.1 课程详情 CTA 状态
```
游客           → 「登录后购买」
已登录未购     → 「立即购买」/（订阅专区）「订阅可看」
已购有效       → 「开始/继续学习」
订阅有效+专区  → 「开始/继续学习」（标订阅中）
已购已过期     → 「已过期，去续费/复购」
```

### 5.2 订单/支付状态（页面感知）
```
UNPAID → (支付成功) PAID → 发权限/可学习
UNPAID → (超时/取消) CLOSED
PAID   → (退款通过) REFUNDED → 回收权限
```

### 5.3 课时锁定状态（详情/播放目录）
```
试看节         → 可直接播放（Try 时长）
已购/订阅有效  → 解锁
未购/已过期    → 锁定，点击引导购买
```

## 6. 埋点与数据需求（页面级，供看板）
- 关键转化：详情页 PV/UV、购买 CTA 点击、收银台到达/支付成功（漏斗）。
- 学习行为：播放开始、心跳时长、完播、课件预览。
- 订阅：订阅页 PV、各周期选择、续费率。
- 异常：支付失败、播放鉴权失败、被踢下线次数。

## 7. 响应式与端差异要点
- **PC 主**：宽屏双栏（播放页左右栏、详情页主信息+侧边购买卡）；扫码登录/扫码支付。
- **H5 辅**：单列、底部 Tab、吸底购买条；公众号授权登录、JSAPI 支付。
- 播放器在 H5 适配竖屏/横屏全屏；水印在两端均生效。
